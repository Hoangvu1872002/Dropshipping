Cách Thức Tùy Biến Nhanh

Section này sử dụng CSS Custom Properties (Variables) đặt ngay tại đầu selector. Bạn có thể dễ dàng thay đổi mà không cần sửa code phức tạp:

  • --marquee-bg: #FAF6F0; : Màu nền dải ảnh (chuẩn tone màu kem ấm áp sang trọng như ảnh mẫu).
  • --item-size: 240px; : Kích thước vuông cạnh của từng ảnh (tự động co lại 180px trên điện thoại).
  • --item-gap: 18px; : Khoảng cách giữa các ảnh.
  • --item-radius: 8px; : Độ cong bo viền của các góc ảnh.
  • --marquee-speed: 32s; : Thời gian hoàn thành 1 chu kỳ chạy (số giây càng lớn thì chạy càng chậm mượt).

Cách Nhúng Vào Shopify / Landing Page / WordPress

1. Bạn chỉ cần chọn tốc độ, hướng chạy, bo góc ở thanh công cụ bên trên. Code xuất ra sẽ tự động giữ đúng 100% các thiết lập đó.

2. Nhấp nút "Sao Chép Code Nhúng (Có Lưu Setup)".

3. Trong Shopify: Vào Online Store > Themes > Customize, thêm block/section dạng Custom Liquid (hoặc Custom HTML) và dán code vào.

4. Trong WordPress / WooCommerce: Thêm block Custom HTML vào vị trí muốn hiển thị.

5. Bạn có thể xem trước đoạn code xuất ra theo thời gian thực ở khung bên dưới:

/* Đang tải cấu hình động... */
Đã sao chép toàn bộ code section vào clipboard!
